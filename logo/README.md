# Logo assets

Mintlify expects two logos referenced from `mint.json`:

- `light.svg` — used on light theme (use a dark/colored mark on transparent background)
- `dark.svg` — used on dark theme (use a light mark on transparent background)

Drop your existing Rentr brand SVGs here with those exact filenames. Optimal dimensions: roughly 100x32px or similar aspect ratio.

You can also use PNGs — just update `mint.json` paths from `.svg` to `.png`.

## Favicon

`mint.json` also references `/favicon.png`. Drop a 32x32 PNG at the repo root (one level up from this folder).
